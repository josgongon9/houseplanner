# Preferencias del usuario

- Arrancar y abrir la aplicación local siempre en http://localhost:5173/. Si ya está levantada, reutilizar el servidor existente.
- En futuras funcionalidades, usar una interfaz concisa: sin eslóganes, subtítulos explicativos ni párrafos de ayuda no solicitados. Mantener etiquetas necesarias, datos y mensajes breves de estado o error.
- La pestaña Organización es un panel para planificar el reparto del dinero; no debe incluir seguimiento de transferencias pendientes o realizadas.
- Priorizar gráficas legibles en móvil, con nombres, importes y porcentajes visibles.
